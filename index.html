Core Features

七个模块，覆盖日常系统优化

从硬件体检到深度清理，删除与卸载前自动备份、可恢复，误操作也有后悔药。

01 · 硬件信息

电脑配置一目了然，截图即分享

一键采集处理器、主板、内存、显卡、显示器、磁盘、声卡、网卡完整硬件信息，顶部三卡展示型号 / 系统 / 运行时间。

  • 八类硬件信息自动采集，无需拆机
  • 显示器显示尺寸与当前 / 最大刷新率
  • 导出带水印截图，方便咨询与分享
02 · 强制删除

删不掉的文件？拖进来就完了

支持文件、文件夹批量拖放删除。自动尝试强制获取权限（takeown + icacls）、结束占用进程，仍失败时标记为重启后删除，绝不半途而废。

  • 批量拖放，多路径同时处理
  • 强制获取权限 + 结束占用进程
  • 失败自动标记，重启后彻底删除
03 · 右键菜单清理

让右键菜单回到清爽的样子

扫描全部右键菜单项，按第三方 / 系统 / 本软件分类统计，显示软件厂商与菜单位置。勾选即可清理，清理前自动备份，随时一键恢复。

  • 分类筛选：全部 / 第三方 / 系统 / 本软件
  • 厂商与菜单位置（桌面 / 文件 / 文件夹）标记
  • 清理前自动备份，按时间点恢复
04 · 软件卸载

卸载软件，连注册表一起清干净

扫描全部已安装软件，显示版本、安装时间、发布者、大小，支持按任意列排序。常规卸载调用官方卸载向导；顽固软件一键强制卸载并清理残留。

  • 安装时间 / 发布者 / 大小一目了然
  • 强制卸载：结束进程 + 清理文件 + 注册表
  • 卸载残留注册表一键清理（仅备份注册表）
05 · 系统更新

更新坏了能修复，不想更新能禁止

深度检测 Windows 更新被禁用 / 限制的配置（服务、hosts、暂停更新等），一键修复被禁用或损坏的更新组件；也可一键禁止自动更新，防止后台占用与强制重启。

  • 检测禁用配置：服务 / hosts / 暂停更新
  • 一键修复 Windows 更新服务与依赖项
  • 一键禁止 / 恢复自动更新，防后台占用
06 · 服务优化

扫描全部服务，找到拖慢电脑的元凶

检测系统全部服务（数百项），自动归类系统 / 第三方并读取厂商信息，内置推荐禁用清单。一键禁用后台占用服务，随时一键恢复。

  • 扫描全部服务，按系统 / 第三方分类
  • 推荐禁用 / 谨慎禁用风险分级 + 厂商标注
  • 一键禁用 / 恢复，禁用后提示重启生效
07 · 开机启动项

开机慢？看看这些常驻程序

扫描注册表 Run 键与启动文件夹的全部启动项，显示命令、厂商与来源。一键禁用不常用的自动启动程序，明显加快开机速度、释放内存。

  • 注册表 HKCU / HKLM + 启动文件夹全覆盖
  • 厂商与来源标注，禁用 / 启用一键切换
  • 禁用项自动备份，可随时还原
